# Etapa 02 — JavaScript ES6

Abra o Console com `F12`. O script demonstra `const`, `let`, tipos, operadores, strings, template literals e `if/else`.

## Exemplo rápido

```javascript
const nome = "Ana";
const mensagem = `Olá, ${nome}!`;
console.log(mensagem);
```

O template literal permite inserir o valor de uma variável dentro de uma string usando `${}`.

## Desafio

Troque os valores das variáveis, observe o resultado e crie uma nova mensagem usando template literal.
