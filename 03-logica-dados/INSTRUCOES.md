# Etapa 03 — Lógica, arrays e objetos

O código usa uma lista de objetos, uma função, um laço e uma condição para calcular uma informação.

## Exemplo rápido

```javascript
const produto = { nome: "Teclado", preco: 100 };
const produtos = [produto];

produtos.forEach(function (item) {
  console.log(item.nome);
});
```

O objeto representa um item; o array reúne vários itens; o laço percorre a lista.

## Observe

- como um objeto representa um item;
- como o array guarda vários itens;
- como a função recebe dados;
- como o `forEach` percorre a lista;
- como o `if` toma uma decisão.

## Desafio

Adicione um objeto ao array e crie uma condição para destacar itens com nota maior ou igual a 8.
