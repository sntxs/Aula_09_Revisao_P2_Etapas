# Etapa final — Integração

Nesta etapa, a interface reúne formulário, Bootstrap, DOM, validação e as quatro operações HTTP.

## Fluxo

1. `GET` carrega os posts da API.
2. `POST` envia um novo post.
3. `PUT` atualiza o post cujo ID foi informado.
4. `DELETE` solicita a exclusão do post cujo ID foi informado.

## O que explicar

- qual evento inicia cada requisição;
- qual endpoint é usado;
- quando existe `body`;
- como a resposta é validada;
- como o feedback é alterado na tela;
- quais cuidados seriam necessários em uma API real.

## Desafio

Faça a listagem mostrar também o título dos posts retornados pelo GET e adicione um botão para limpar as mensagens.
